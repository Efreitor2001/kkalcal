БАЗОВЫЕ ПРОДУКТЫ ПРИЛОЖЕНИЯ «БАЛАНС»
Подготовлено 2026-10-08.

127 записей отобраны из официального USDA FoodData Central SR Legacy (финальный выпуск Standard Reference, апрель 2018).
Исходный JSON скачан напрямую с USDA; числовые КБЖУ извлечены программно, а не набраны по памяти.
Данные SR Legacy справочные: сорта, производители, состав и способ приготовления влияют на конкретный продукт.
Для упакованного продукта пользователь может заменить значения на данные с этикетки.
Все КБЖУ указаны на 100 г съедобной части; вес костей, косточек и несъедобной кожуры не включается.
Сухая крупа и готовая каша заведены отдельными продуктами. Для готового блюда с добавленными ингредиентами учитывайте его полный состав.

Соответствие полей:
kcal    = nutrient.id 1008 Energy, kcal
protein = nutrient.id 1003 Protein, g
fat     = nutrient.id 1004 Total lipid (fat), g
carbs   = nutrient.id 1005 Carbohydrate, by difference, g

Углеводы USDA (carbohydrate by difference) включают пищевые волокна. Поэтому эти значения могут отличаться от маркировки продуктов, использующей другой способ подсчёта углеводов.
Энергия сохранена отдельным значением из USDA; она не пересчитывается по универсальной формуле 4/9/4.
Число знаков после запятой сохранено из источника и не означает гарантированную точность для каждого экземпляра продукта.
«Творог зернёный 2%» — cottage cheese, а не обычный сухой творог. Это явно указано в названии и примечании.
Названия и категории переведены для приложения. Сопоставление каждой записи с оригинальным названием и FDC ID приведено ниже.

Проверки:
— 127 уникальных id и 127 уникальных названий.
— Для каждой записи найдены все 4 нужных показателя в исходном USDA JSON.
— Значения конечные и неотрицательные: kcal <= 1000; каждый макроэлемент <= 100 г.
— Сумма Б+Ж+У не превышает 101 г (допуск на исходное округление); по этим продуктам фактический максимум 100 г.
— Идентификатор seed_<NDB> сохраняет стабильную привязку к записи источника.
— Интернет требуется только при подготовке базы; файл assets/products.json полностью автономен.
