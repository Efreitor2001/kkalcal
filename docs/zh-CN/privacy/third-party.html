Yandex Mobile Ads 8.5.0

提供者：Yandex（根据其政策，为 YANDEX LLC 及适用的关联公司）。用途：加载和展示广告、衡量广告互动，以及 SDK 的技术运行。

数据：IP 地址和网络请求信息；设备、操作系统及应用信息；可用的广告及技术标识符；广告请求、展示、点击和技术诊断信息。应用不会将日记内容、Google 电子邮件地址或 Google 账号标识符加入广告参数。

处理时间：在已验证的去广告权益尚未生效时，应用或广告位打开可能初始化 SDK，而不先显示单独的同意弹窗。应用设置 setUserConsent(false)、setLocationTracking(false) 和 setAppAdAnalyticsReporting(false)。位置跟踪和 App Ad Analytics 报告已关闭，应用不请求精确或大致位置权限。这些设置不是对所有网络处理的统一禁止。有效的付费许可验证通过后，应用隐藏广告、停止自身发起的广告请求并释放缓存的广告对象；这不保证当前会话中已启动 SDK 的全部后台工作停止。应用没有单独的广告同意开关。

提供者规则：隐私政策及请求渠道；SDK 数据说明。保留期限及国际处理由提供者确定；清除日记并不等于向 Yandex 提出删除请求。

以下分别说明广告 SDK 的依赖组件。数据类别描述的是相应组件的能力，并不表示每台设备上都已开启全部功能。构建包含某个库，本身不证明其已启动或传输数据。应用不直接调用这些辅助 API，也不向其提供日记记录。

AppMetrica 8.5.0

提供者：Yandex（YANDEX LLC 及适用的关联公司）。组件用途：技术诊断、应用及广告效果衡量；作为 Yandex Mobile Ads 的依赖包含在构建中。

数据类别：设备、操作系统及应用的技术信息、崩溃与性能信息，以及可用的 SDK 和广告标识符。广告事件取决于已启用的功能。应用未配置单独的日记操作统计，也不发送包含日记内容的自定义事件。

访问方式与条件：相应 SDK 模块在运行时通过 Android 及库的 API 获取技术信息，并可能将其发送至 Yandex 服务。本构建在广告初始化前关闭 App Ad Analytics 和位置跟踪；这并不证明所有 SDK 内部诊断均被关闭。

Yandex 隐私政策 · AppMetrica 数据类别 · Ads 集成及报告控制。

Varioqub 适配器 0.6.0

提供者：Yandex（YANDEX LLC 及适用的关联公司）。组件用途：连接 SDK 配置、实验及分析系统。广告依赖包含 Varioqub 适配器；开发者未对日记配置独立实验。

数据类别：使用相应集成时，涉及项目标识符、Varioqub 技术标识符、配置参数及激活事件。自定义参数需要集成代码明确提供；应用不向其提供日记内容、Google 邮箱或令牌。

访问方式与条件：适配器将调用它的 SDK 与 AppMetrica 连接；联网更新配置及发送事件取决于相应集成的初始化和调用。日记代码不直接调用 Varioqub；存在适配器不代表所有实验功能已开启。

Yandex 隐私政策 · Varioqub 集成文档。

Google Advertising ID 18.1.0

提供者：Google LLC 及适用的关联公司。组件用途：为广告组件及广告效果衡量提供广告标识符；该库通过 AppMetrica 依赖引入。

数据类别：Google 广告标识符（GAID）及限制广告跟踪的设置状态。它们不同于 Drive 使用的 Google 邮箱和账号标识符。

访问方式与条件：收到请求时，库调用设备上的 Google Play services API。可用性取决于服务、用户设置及 AD_ID 权限；本构建包含该权限。标识符受限时，可能返回全零值或无法访问。读取标识符与随后由广告 SDK 处理标识符是不同操作；存在依赖不证明一定传输了非零 GAID。

Google 隐私政策 · Advertising ID 文档。

Google App Set ID 16.1.0

提供者：Google LLC 及适用的关联公司。组件用途：为分析用途在技术上识别设备上的应用或应用集合，与广告标识符不同。

数据类别：App Set ID 及其作用范围，即单个应用或某开发者的应用集合。它不是 Google 账号，也不是日记内容。

访问方式与条件：调用组件通过 App Set ID 库的 API 请求标识符。作用范围取决于安装来源及可用服务；文档规定，非 Google Play 安装使用单个应用范围。本构建中的第三方 SDK 可以使用该库，但日记代码没有单独发起请求。

Google 隐私政策 · App Set ID 文档。

Google Play Install Referrer 2.2

提供者：Google LLC 及适用的关联公司。组件用途：获取安装来源信息，供第三方 SDK 进行安装归因。

数据类别：商店可提供的安装来源字符串、点击及开始安装时间、首次安装时的应用版本，以及 Instant experience 互动标记。

访问方式与条件：客户端库向设备上的 Google Play Store 服务查询，需要受支持的商店及可用数据。在 Huawei 构建中包含该库，并不表示每位 AppGallery 用户都有 Google Play 或相应的来源数据。日记不直接调用此库。

Google 隐私政策 · Install Referrer 文档。

Google 登录与 Drive；AppAuth Android 0.11.1

接收方：根据 Google 政策，为 Google LLC 及适用的关联公司。用途：可选的账号连接、备份快照及跨设备日记合并。

数据及时间：在你选择连接之后，处理 OAuth 请求、电子邮件地址、账号标识符及令牌；同步时，处理日记内容、设置及更改元数据。数据直接发送至 Google。访问权限仅限 openid、email 和 drive.appdata。登录后执行首次同步，之后按设置自动同步或由你手动启动。

如果购买已确认，可转移设置会包含签名去广告许可文件。根据你的选择，它可以进入 Google Drive 和 JSON 导出文件。文件不含银行卡信息或支付表单中的邮箱，在技术上也不与 Google 账号绑定；请勿公开该文件或包含它的完整备份。

AppAuth 是用于浏览器登录、令牌交换和刷新的开源客户端库。在本应用的集成中，它连接的是 Google；OpenID 组织不是独立接收日记的服务器。AppAuth 文档。

Google 隐私政策 · 权限与保护措施 · Google Limited Use · 断开连接与删除。应用不选择 Drive 数据的存储国家，也不对 JSON 快照提供端到端加密。

Robokassa：可选支付

接收方：ООО «РОБОКАССА»（ROBOKASSA LLC）及你所选支付方式的服务提供者。用途：以一次性 149 俄罗斯卢布购买永久去广告权益，并出具支付凭证；没有订阅或自动重复支付。

数据及处理方式：选择支付后，经本地适配的 Robokassa Android SDK 会打开支付网页表单。你在其中填写支付信息和邮箱。Robokassa 还会接收订单参数及请求的技术数据。日记代码不会读取已填写的支付信息，也不会将其存入支付服务器的数据库。日记内容、健康信息和 Google 数据不会发送至 Robokassa。

处理时间：仅在你使用可用的购买功能时；构建包含 SDK 不表示真实支付已经启用。条款和处理规则见 Robokassa 隐私政策及卖方要约（俄文）。清除日记不会删除依法必须保留的交易记录及支付凭证。

Cloudflare Workers 与 D1：购买服务器

基础设施提供者：Cloudflare, Inc. 及其政策中适用的实体；日记运营者在该基础设施上配置支付服务。用途：检查购买可用性、创建和确认订单、签发及恢复签名许可，以及限制滥用。

D1 中的数据：支付单号、随机订单及许可标识符、订单访问令牌的哈希值、构建所属商店、测试或正式模式、技术用商户标识符、金额、币种、状态、交易日期及签名许可文件。D1 不保存邮箱、银行卡信息、Google 账号或其令牌、日记内容及健康信息。

核验支付时，Robokassa 的通知和响应可能含有付款人邮箱及支付账户信息。基础设施可能将它们作为消息的一部分进行处理，但代码不使用它们签发许可，也不写入 D1。

网络数据：平台处理 IP 地址和请求的技术信息；IP 对应的国家用于判断购买可用性，包括 Google Play 的俄罗斯限制，IP 也用于限制请求频率。我方 D1 不保存原始 IP；支付应用的请求日志已关闭。Cloudflare 自身的技术处理和日志遵循其规则。使用随机标识符和哈希并不意味着处理完全匿名。

保留与删除：在确认或恢复许可、交易记账及适用要求仍有需要期间，会保留记录；有关期限和删除问题，请联系 pokimoha.123@gmail.com。我们不声称所有基础设施都位于俄罗斯。Cloudflare 隐私政策 · 支付详情 · 购买与删除。

GitHub Pages 与 GitHub Issues

提供者：依据服务政策，为 GitHub, Inc. / GitHub B.V.。本网站由 GitHub Pages 托管。打开页面时，GitHub 会接收提供网站服务所需的网络请求技术信息。开发者未在这里嵌入广告、统计分析工具或登录表单。

如果你创建 GitHub Issue，GitHub 会处理你的账号信息和提交内容；该内容是公开的。请勿在那里发布日记或其他敏感信息。GitHub 隐私声明。

支持邮件 / Gmail

如果你发送邮件至 pokimoha.123@gmail.com，运营者会接收发件地址、正文及附件，以答复请求。邮件保存在 Gmail 中，邮件服务适用 Google 隐私政策。运营者未设定独立的固定保留期限；可通过同一邮箱请求删除发送给支持的信息。

由你选择的文件接收方

保存或分享 JSON 备份时，你会选择文件夹、云端服务或接收方。其处理取决于你的选择及其自身规则；应用无法提供此类接收方的统一清单。

主要日记功能无需 Google、购买或互联网即可使用。各 SDK 和服务不会自动收到相同的数据：饮食记录不会发送给广告服务或支付服务器，Google 同步在连接后才开始。在购买可用的地方，经过验证的许可可以关闭广告。应用没有单独的广告同意开关，也没有针对广告 SDK 的事先同意弹窗。
