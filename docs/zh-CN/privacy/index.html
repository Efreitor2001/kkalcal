1. 设备上的日记

主要功能无需注册或联网即可使用。饮食日记不提供独立的应用账号。应用在设备的专用存储区域保存以下信息：食物、营养值及食物备注；份量、餐次名称和日期；体重、腰围、体脂率、步数、睡眠、训练描述、备注、手动输入的每日热量和蛋白质；目标、成就、设置及更改元数据。

这些信息用于计算热量、蛋白质、脂肪和碳水化合物，并提供历史记录、图表、目标和成就。选填字段可以留空。步数、睡眠和测量值均为手动输入；应用不读取 Health Connect、身体活动传感器或医疗设备的数据。

敏感的健康信息。你输入的饮食、体重、腰围、体脂率、睡眠、活动及身体状况备注可能涉及健康信息。应用在设备上处理这些数据，用于计算、历史记录、图表和目标管理。如果你选择连接 Google Drive，这些信息也会包含在完整的日记快照中，用于备份和在你的设备之间同步；导出时，这些信息会写入你选择的 JSON 文件。这些信息不会作为广告参数传递。

你可以将选填字段留空，也可以不连接 Google Drive。请勿在自由文本备注中填写不必要的信息。开发者不运营接收日记内容的服务器。如果你不连接 Google Drive，也不分享备份，记录将保留在设备上。

2. 可选的 Google Drive 连接

根据你的操作，应用会在系统浏览器中打开 Google 登录，并请求以下 OAuth 权限：

openid
获取所选 Google 账号的唯一标识符，用于在登录或切换账号时，将同步状态关联到正确的账号。
email
获取电子邮件地址及其验证状态，用于检查和显示已连接的账号。
https://www.googleapis.com/auth/drive.appdata
在你的 Google Drive 隐藏应用数据文件夹 appDataFolder 中创建、列出、读取和删除本应用自己的快照。应用不请求访问 Drive 中的一般文档或照片。

应用不请求访问 Gmail 邮件、通讯录或日历。Google 密码由你在 Google 页面输入，不会提供给应用。

授权数据。应用接收电子邮件地址、账号标识符、邮件验证状态、访问令牌及刷新令牌。这些信息用于连接账号、显示账号，以及在无需反复登录的情况下执行获准的数据交换。本地授权会话经过加密；同步缓存（包括账号标识符）保存在应用的专用设置中。这些信息不会上传至开发者服务器，也不会加入日记 JSON 备份。

上传到云端的内容。快照包括食物及营养值、份量和用餐日期、测量值及其他手动输入的指标、备注、训练、目标、成就、可转移的设置，以及用于合并数据的随机安装标识符、时间戳和删除标记。应用会读取自己的快照，包括由你的其他设备创建的快照，将其与本地记录合并，并将结果保存在设备上。应用还会读取文件标识符、创建时间和安装标记，以查找及清理快照。

交换时间。连接后会执行首次同步。自动同步默认开启，可在“云端同步”页面关闭。开启后，应用会在数据更改时、启动时及有网络连接的后台状态下进行同步。你也可以手动同步。关闭自动同步不会删除已有副本。

接收方。授权请求和快照由设备直接发送至 Google 服务。你的其他设备连接同一账号后可以接收这些快照。开发者没有你的 Drive 管理权限。Google 数据不会提供给广告 SDK。Google 的处理规则见 Google 隐私政策。

Google 数据的有限使用 / Limited Use

本应用遵守 Google API 服务用户数据政策，包括其中的有限使用要求。

The app complies with the Google API Services User Data Policy, including its Limited Use requirements.

Google 数据和 Google Workspace API 数据不会用于开发、改进或训练人工智能及机器学习模型，包括通用或非个性化模型。日记处理不包含 AI/ML 功能。开发者不会查看你的 Drive 或日记内容。你联系支持时，开发者只能看到你主动提供的信息；无需提供 Google 密码、令牌或完整日记备份。

3. 导出与恢复

“保存到文件”会在你选择的位置创建 JSON 文件。恢复功能只读取你选择的文件。备份包含日记记录和更改元数据，但不包含 Google 电子邮件地址、账号标识符或令牌。应用不会加密此 JSON 文件。如果你选择云端文件服务或将备份发送给他人，接收方由你决定，其规则另行适用。

4. 广告及技术数据

应用使用 Yandex Mobile Ads SDK 及其依赖中的 AppMetrica 和 Varioqub 组件。加载和展示广告需要连接广告服务。Yandex 可能处理 IP 地址、请求及设备和软件的技术信息、可用的广告或技术标识符、诊断信息，以及广告展示和互动信息。组件及其用途见第三方 SDK 与服务清单。

当前版本的实际行为。应用启动或广告位打开时，广告 SDK 可能在未先显示单独同意弹窗的情况下启动。应用向 SDK 传递“未获得同意”的标记，并关闭位置跟踪及 App Ad Analytics 报告。这些设置不会禁用 SDK，也不代表没有网络通信。当前应用没有单独的同意开关或关闭广告的选项。

应用不请求精确或大致位置权限。Android 构建包含广告标识符权限 AD_ID；其可用性取决于设备和系统。如果系统支持，你可以在 Android 设置中管理广告标识符，但这不会停止所有技术数据处理。

应用不会将饮食、体重、测量值、备注、目标、Google 电子邮件地址或账号标识符加入广告请求参数，也不会使用这些信息进行广告定向。观看广告不是保存记录的条件。离线日记可以在没有网络时使用，但断开网络也会阻止 Google 同步。

广告服务数据的处理、保留和删除请求适用 Yandex 隐私政策。日记开发者不为此类数据设定独立的保留期限，也不能承诺清除日记会一并删除广告服务的数据。

5. 安全、权限及处理地点

与 Google 的通信使用 HTTPS。登录采用系统浏览器、请求状态校验和 PKCE。本地 Google 会话（包括令牌）使用 Android Keystore 密钥进行 AES-GCM 加密。断开账号连接后，会删除本地会话文件及连接缓存。Yandex 声明其 SDK 数据通过 HTTPS/TLS 传输。

本地日记及设置受 Android 应用隔离机制保护。应用不会对日记、导出的 JSON 或云端 JSON 快照进行额外加密；不提供设备之间的端到端加密。应用数据的系统备份已关闭。从旧格式迁移时，可能会保留一份内部备份。

应用使用互联网和网络状态访问权限。后台任务组件还会声明用于唤醒锁、设备启动后重新安排任务及前台服务的 Android 技术权限。导入和导出的文件由系统文件选择器选择；应用不请求访问全部存储空间的广泛权限，也不请求相机、麦克风、通讯录、短信或位置权限。

应用自身代码记录的诊断日志包含结果代码，不包含日记内容、电子邮件地址、令牌或网络响应正文，也不会单独发送给开发者。此说明不排除第三方广告 SDK 自身的技术诊断处理。

运营者位于俄罗斯。Google、Yandex 和 GitHub 可能按照其政策，在与你所在国家不同的国家处理数据。应用不提供存储地区选择，也不承诺将数据存储在中国大陆。第三方服务的可用性取决于地区及网络；主要离线日记功能不依赖这些服务。

6. 保留期限与删除

本地记录会保留到你修改、删除记录或清除应用数据为止。删除单条记录会将其从界面中隐藏，并在同步时发送删除标记。为防止旧快照恢复该记录，合并元数据可能保留已删除日记字段的旧值。旧值也可能存在于历史云端快照和已导出的备份中。

数据发生变化时，应用会在 Google Drive 创建一份完整的新快照。上传成功后，应用会尝试删除由同一安装实例创建的更早快照，仅保留新快照和上一份快照；其他安装实例的快照不受影响。清理失败可能留下更多副本。应用没有设定自动删除所有快照的固定期限。

Google 会话会保留到你断开连接或清除应用存储为止；令牌失效时可能需要重新登录。“断开账号连接”会停止此设备上的同步并删除本地会话，但保留日记和云端副本，不会撤销 Google 端的授权本身，也不会删除 Google 账号。

如需删除全部副本：

  1. 在所有设备上断开 Google 连接。如果无法使用应用，请先在 Google 账号关联管理中撤销应用访问权限。
  2. 使用相应账号打开 Google Drive 设置，选择“管理应用”，找到登录时显示的应用名称，再选择“选项”→“删除隐藏的应用数据”。必要时使用桌面版网站或电脑。
  3. 如果尚未撤销 Google 访问权限，请撤销。仅撤销授权不会删除快照。
  4. 在每台设备的 Android 设置中清除应用数据或卸载应用。这也会删除内部备份及本地会话。
  5. 单独删除你选定的文件夹和云端存储中的已导出 JSON 文件。

重新连接仍有记录的设备可能再次创建云端副本。无需重新安装应用即可查看详细删除说明。开发者无法远程擦除你的设备或个人 Drive，请勿提供密码或令牌。
